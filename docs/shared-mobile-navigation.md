# Shared compact mobile navigation

The shared header lives in `client/src/components/site-navigation.tsx`; App uses it once across the site. Below 1024px, a 64px row contains the brand, existing Work Together CTA, and labeled Menu/Close button. The brand simplifies to its approved logo below 360px, logo plus Clarity at 360–429px, and full name at 430px and above. Controls retain 44px targets and readable type. The existing desktop navigation is preserved.

The disclosure groups seven existing destinations under Find your next step and Explore Clarity Engine, marks the current route/section, and closes on selection, navigation, Escape, or resizing to desktop. Escape returns focus to the menu button. Hidden panel links are removed from keyboard navigation by the native hidden attribute. The panel overlays beneath the fixed row without altering its measured height, so shared anchor offsets remain accurate. On short/landscape screens it scrolls internally within the dynamic viewport; reopening resets its scroll position.

App's shared header clearance was reduced to match the removed mobile link row: non-home routes use 80px clearance, and the homepage's existing header allowance is reduced by 56px below the desktop breakpoint. Hero text, media behavior, internal layouts, offers, prices, payment links, and footer navigation are unchanged. Reduced-motion navigation anchors jump immediately rather than inheriting the site's global smooth scrolling.

Verification: TypeScript, build, metadata checks; 320/360/390/430/600/768/820/960 widths, short 568×320 and landscape 844×390, desktop 1024/1440. Native touch panel scrolling checked on short landscape; selecting closes and reopening resets. Desktop before/after screenshots at 1440×1000 are pixel-identical (0 differing channels).
