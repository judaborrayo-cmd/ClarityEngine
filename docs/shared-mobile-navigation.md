# Shared compact mobile navigation

The shared header lives in `client/src/components/site-navigation.tsx`; App uses it once across the site. Below 1024px, a 56px top row holds the approved brand, Work Together overview CTA, and labeled Menu/Close button. A 44px second row provides Services, Case Studies, and Explore Offers with a chevron. Including dividers, closed header height is 102px. Brand simplifies below 430px to preserve readable controls; all header targets are at least 44px. The existing desktop navigation is preserved.

A single `menu | offers | null` state ensures only one disclosure is open. Explore Offers shows five information links with the supplied descriptions and no prices: assessment sales page, Sprint sales page, existing /growth-clarity-audit information page, /#book-intro, and /services for retainer details. These destinations match the existing site/offer overview. None goes directly to Stripe. Main Menu provides all five offers plus Work Together, Services, Case Studies, How We Scale and About. Both panels highlight the current route/section and close on selection, navigation, Escape, or switching to desktop. Escape and explicit closing return focus to the relevant toggle. Native hidden attributes keep closed-panel links out of keyboard navigation.

Panels overlay beneath the fixed header without altering its measured height. They scroll internally within the dynamic viewport on short and landscape screens, and reset their scroll position when reopened. Explore Offers includes an explicit Close offers action; Menu changes to Close with an X. Caret transitions respect reduced motion, and shared route/anchor scrolling jumps immediately when reduced motion is requested.

App's shared clearance matches the two-row header: non-home mobile routes use 112px clearance (desktop remains 80px), and the homepage's existing mobile header allowance is reduced by 24px (desktop unchanged). Hero contents/internal layouts, animation behavior, offers, prices, payment links, footer navigation and other page sections are unchanged.
